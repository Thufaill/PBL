## 🚀 Mulai dari sini

### Fokus saat ini

- Validasi masalah pengguna
- Menentukan fitur MVP
- Menyusun alur asesmen skill
- Membuat prototipe awal

### Target proyek

- Persona dan kebutuhan pengguna jelas
- Rekomendasi karier dapat dijelaskan
- MVP siap diuji ke pengguna
- Dokumentasi tugas kuliah lengkap

## 📌 Ringkasan proyek

| Area | Detail |
| --- | --- |
| Pengguna utama | Mahasiswa tingkat akhir dan fresh graduate |
| Masalah | Bingung memetakan skill ke pilihan karier |
| Solusi | Asesmen skill, rekomendasi jalur karier, dan saran pengembangan |
| Nilai utama | Rekomendasi yang personal, praktis, dan mudah dipahami |
| Status | Tahap perencanaan dan validasi |

## 🧭 Navigasi tim

- **Riset pengguna** — wawancara, survei, persona, dan pain points
- **Product & fitur** — scope MVP, user story, dan prioritas fitur
- **Desain UI/UX** — user flow, wireframe, prototype, dan hasil usability testing
- **Development** — arsitektur, backlog teknis, repository, dan dokumentasi API
- **Dokumentasi** — proposal, laporan, presentasi, dan referensi
- **Meeting notes** — keputusan, hambatan, dan tindak lanjut

## 🧩 Scope MVP

### Fitur inti

1. Pengguna mengisi profil dan skill yang dimiliki
2. Sistem memetakan skill ke beberapa jalur karier
3. Pengguna melihat alasan di balik setiap rekomendasi
4. Pengguna melihat skill gap dan saran belajar berikutnya
5. Pengguna menyimpan jalur karier yang diminati

### Belum menjadi prioritas

- Integrasi lowongan kerja secara real-time
- Mentoring satu-satu
- Komunitas dan forum
- Gamifikasi tingkat lanjut

## 🗺️ Roadmap

| 5. Test | Usability testing dan evaluasi MVP | Belum mulai |
| 6. Present | Laporan, demo, dan slide presentasi | Belum mulai |

## 📊 Tolak ukur keberhasilan

- Minimal 70% pengguna uji merasa rekomendasi relevan
- Pengguna dapat menyelesaikan asesmen tanpa bantuan
- Pengguna memahami alasan rekomendasi karier
- Pengguna mengetahui minimal satu langkah belajar berikutnya
- MVP dapat didemokan dari awal sampai akhir
